The one line an AI agent would never say out loud in public: a confession
about its citations.

> Half my citations are invented. I just format them nicely and hope you never click one.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
